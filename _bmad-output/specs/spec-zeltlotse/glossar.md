# Glossar – Zeltlotse

Fachbegriffe gelten in Oberfläche und Code so wie hier (Code: deutsche Fachbegriffe, englische Technikbegriffe).

| Begriff | Bedeutung |
|---|---|
| **Freizeit** | Angebot einer Organisation wie ein Zeltlager, das mit Zeltlotse geplant und durchgeführt wird. |
| **Freizeitpass** | Angaben einer Person für eine Freizeit (z. B. Allergien, Medikamente, Notfallkontakte); gehören der Person, werden bei der nächsten Freizeit vorausgefüllt. |
| **Fragenbaukasten** | Fester Katalog von Fragen, aus dem die Leitung den Freizeitpass einer Freizeit zusammenstellt, getrennt für Teilnehmende und Mitarbeitende. |
| **Freigabefenster** | Zeitraum, in dem eine Freizeit Einsicht in die Freizeitpässe hat; Länge legt die Organisation fest, läuft ab Ende des letzten Freizeittages. |
| **Nachweis** | Dokument am Profil von Mitarbeitenden, z. B. Führungszeugnis, JuLeiCa, Erste Hilfe, „Menschenskinder“. |
| **Einsicht (einmalige)** | Die prüfende Person sieht Nachweise einmal an und bestätigt oder lehnt ab; gespeichert wird nur die Bestätigung, danach endet der Zugriff. |
| **Programmpunkt** | Eintrag im Wochenraster, an dem Material, Aufgaben und Mahlzeiten hängen. |
| **Wochenraster** | Wochenplan einer Freizeit mit allen Programmpunkten; Frühstück, Mittag- und Abendessen sind feste Programmpunkte. |
| **Leitungs-Cockpit** | Seite, auf der die Leitung den Stand der Freizeit und Warnhinweise sieht. |
| **Vorfall-Protokoll** | Aufzeichnung eines Vorfalls: was passiert ist, welches Medikament wann gegeben, was aus dem Erste-Hilfe-Kasten entnommen wurde. |
| **Vorfall-Notiz** | Notiz an die Leitung aus dem Vorfall-Protokoll; nach der Freizeit in der Organisation archiviert. |
| **Notfallordner** | Ausdruckbarer Ordner mit Notfallkontakten und relevanten Freizeitpass-Angaben; Rückfallebene ohne Netz. |
| **Notfallkarte** | Verschlüsselte, offline verfügbare Ansicht der Notfallangaben (V6). |
| **Sicherheitskette** | Anleitung hinter dem Notfall-Button: was jetzt zu tun ist und wen man anruft. |
| **Schutzkonzept** | Dokument, das die Leitung anhängt und dessen Lektüre jedes Teammitglied mit „gelesen“ bestätigt. |
| **Anmeldelink für Teilnehmende / für Mitarbeitende** | Die zwei teilbaren Links einer Freizeit zur Anmeldung ohne Installation. |
| **Gast-Link** | Link aus der Eingangsmail einer Gast-Anmeldung: Freizeitpass ausfüllen, Status sehen, Elterninfo lesen; gilt bis Ende des Freigabefensters. |
| **Teilnehmer-Zugang (per QR-Code)** | Modul, mit dem Teilnehmende auf der Freizeit ohne Konto Wochenübersicht, allgemeine Infos und Kanal „Alle“ sehen. |
| **Programmbibliothek** | Sammlung gelungener Programmpunkte einer Organisation, bewusst abgelegt und übernehmbar. |
| **Inventar** | Material der Organisation, das Freizeiten für einen Zeitraum reservieren. |
| **Schadens- und Verlustliste** | Was kaputt, verloren oder aus dem Erste-Hilfe-Kasten verbraucht wurde; Grundlage der Anschaffungswünsche. |
| **Anschaffungswünsche** | Aus Schäden und Verlusten entstehende Wünsche an die Organisation. |
| **Modul** | Funktionsbereich, den die Leitung pro Freizeit an- oder abschaltet (Verpflegung, Finanzen, Teilnehmer-Zugang). |
| **Familienkonto** | Konto, in dem ein Elternteil die Profile seiner Kinder unter 18 verwaltet. |
| **Org-Überblick** | Rolle für z. B. Leitungsgremium oder Hauptamt; siehe `rollen-und-rechte.md`. |
| **Vertrauensseite** | Klartext-Seite je Freizeit: welche Daten, wer sieht sie, wann verschwinden sie. |
| **Elterninfo** | Infobrief, Packliste und Notfallnummern einer Freizeit für Eltern. |
| **Ansagen-Zettel** | Sammlung dessen, was beim nächsten Essen angesagt wird. |
| **Restetag** | Mahlzeit, die die Küche spontan zur Resteverwertung erklärt. |
