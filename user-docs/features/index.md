# Funktionen

Diese Übersicht wächst mit jedem Lauf. Aktuell enthalten:

- **Organisationen** — Träger werden vom Betreiber aufgenommen und bekommen eine
  eigene Adresse.
- **Freizeiten** — je Organisation anlegbar, mit Name, optionalem Zeitraum und
  Ort sowie dem Status „Offen" oder „Geschlossen".
- **Team und Rollen** — Organisationsleitung, Freizeitleitung und Mitarbeitende,
  jeweils über Einladungslinks.
- **Papierkorb** — gelöschte Freizeiten bleiben 30 Tage wiederherstellbar.
